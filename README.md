Vending Machine
Make a program that simulates the actions of a vending machine. At the most basic level, there
could be just one price, and the program waits for just a few different keystrokes indicating
nickel, dime, or quarter, until that amount has been paid. Then the change is given (probably by
printing out some indication of which coins it includes) and the program terminates. To make
the program more sophisticated, you could have multiple items with different prices, allow
more denominations of money (penny, 1/5/10/20 dollar bills, ...), or read some or all of these
specifications from a text file.

Eye of newt         72.28
Toe of frog         15.64
Wool of bat         10.40
Tongue of dog       8.23
Adder's fork        11.80
Blindworm's sting   6.99
Lizard's leg        3.48
Howlet's wing       16.16
